## API Docs
- Packages [Create a shipment](https://docs.logestechs.com/create-a-shipment-42089768e0.md): Creates a package for the customer that owns this API key. There is no email/password or company-id to send — both are resolved from the key. The shipment fields, `originAddress` and `destinationAddress` all go directly in the request body. If `originAddress` is omitted, the customer's own address is used. The service type is always STANDARD. The delivery cost is always calculated from the customer's shipping rates.
- Packages [Generate an AWB PDF for one or more packages](https://docs.logestechs.com/generate-an-awb-pdf-for-one-or-more-packages-42089769e0.md): Accepts up to 100 identifiers total, mixed across `ids`, `barcodes`, and `invoicesNumbers`. Every matched package must belong to this key's customer.
- Packages [Get a package's current status](https://docs.logestechs.com/get-a-packages-current-status-42089771e0.md): Provide exactly one of `id`, `barcode`, or `invoice`.
- Packages [Get a package's full status history](https://docs.logestechs.com/get-a-packages-full-status-history-42089772e0.md): Provide exactly one of `id`, `barcode`, or `invoice`.
- Packages [List the possible package statuses](https://docs.logestechs.com/list-the-possible-package-statuses-42089770e0.md): Static reference data — the full set of statuses a package can be in, with English and Arabic labels. Does not require a specific package.
- Packages [Cancel a package](https://docs.logestechs.com/cancel-a-package-42089767e0.md): Cancels a package before it is picked up. Provide exactly one of `id`, `barcode`, or `invoice`. Only packages still pending customer-care approval or dispatcher assignment can be cancelled; anything further along must go through the help center.
- Packages [Return a package to sender](https://docs.logestechs.com/return-a-package-to-sender-42089766e0.md): Requests a return for a package already out for delivery. Provide exactly one of `id`, `barcode`, or `invoice`.
- Packages [List the company's service types](https://docs.logestechs.com/list-the-companys-service-types-42226516e0.md): The delivery service types this company offers — use `id` when filling in `pkg.serviceTypeId` on a shipment.
- Packages [Calculate a shipment's delivery cost](https://docs.logestechs.com/calculate-a-shipments-delivery-cost-44175741e0.md): Returns the delivery cost the company charges this API key's customer for a shipment with the given origin/destination regions, service type and size. Uses the customer's own shipping rates; any `customerId` in the body is ignored.
- Packages [List the company's vehicle types](https://docs.logestechs.com/list-the-companys-vehicle-types-44230940e0.md): The vehicle types this company offers — use `id` when filling in `pkg.vehicleTypeId` on a shipment.
- Packages [List the company's parcel types](https://docs.logestechs.com/list-the-companys-parcel-types-44230941e0.md): The parcel types this company offers — use `id` when filling in `pkg.parcelTypeId` on a shipment. Names are returned in the language of the request's language header.
- Webhooks [Update your webhook URL and token](https://docs.logestechs.com/update-your-webhook-url-and-token-46611088e0.md): Changes where shipment status updates are sent for the customer that owns this API key, and the token sent with them. Every webhook call after this one uses the new values. `webhookPassword` replaces the current token; leave it empty to stop sending a token.
- Addresses [List the company's address book](https://docs.logestechs.com/list-the-companys-address-book-42089773e0.md): Regions, cities, and villages configured for this company — use these IDs when filling in `originAddress`/`destinationAddress` on a shipment.
- Addresses [List regions](https://docs.logestechs.com/list-regions-42225832e0.md): Regions configured for this company — use `id` when filling in `originAddress`/`destinationAddress` on a shipment.
- Addresses [List a region's cities](https://docs.logestechs.com/list-a-regions-cities-42225854e0.md): Cities configured for this company within the given region — use `id` when filling in `originAddress`/`destinationAddress` on a shipment.
- Addresses [List a city's villages](https://docs.logestechs.com/list-a-citys-villages-42226478e0.md): Villages configured for this company within the given city — use `id` when filling in `originAddress`/`destinationAddress` on a shipment.
- Addresses [List villages](https://docs.logestechs.com/list-villages-44175742e0.md): Villages configured for this company, paginated, optionally narrowed to a city, a region, a name search, or the destination city of one of your packages (`barcode`) — use `id` when filling in `originAddress`/`destinationAddress` on a shipment.
- Fulfillment [Add a product](https://docs.logestechs.com/add-a-product-46650412e0.md): Adds a product (SKU) to the fulfillment catalog of the customer that owns this API key. Use the returned `id` as `productId` when you add an ASN or an order.
- Fulfillment [Add an ASN](https://docs.logestechs.com/add-an-asn-46650413e0.md): Announces stock you are sending into a fulfillment warehouse (Advance Shipping Notice). Every product must be one of your own products. The ASN starts in status `AWAITING_PICKUP`.
- Fulfillment [Add an order](https://docs.logestechs.com/add-an-order-46650414e0.md): Creates an outbound order that the warehouse picks from your stock and delivers to the receiver. Every item must be one of your own products. The sender address is the warehouse's address. If there is not enough stock for every item, the order is still created and stays `PENDING` until the stock arrives.
