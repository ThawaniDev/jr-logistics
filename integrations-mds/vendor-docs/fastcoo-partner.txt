Introduction
Fastcoo Partner API Integration allows companies participating in the Fastcoo Partner Program to
connect their e-commerce or order management systems directly with Fastcoo and supported
third-party courier services. Through the Fastcoo Partner API, they can automate a wide range of
logistics and fulfillment operations, including order creation, shipment tracking, pickup
scheduling, cancellations, rate calculations, and shipping label generation — all without the
need for manual integrations with multiple carriers.
This integration helps streamline order processing, ensures real-time shipment updates, and
simplifies the entire last-mile delivery workflow.

Rate Limiting
To ensure fair use of system resources and maintain consistent performance, the Fastcoo Partner
API enforces a rate limit policy on order creation requests.
Limit: Maximum 180 order creation requests per minute
Enforcement: If the limit is exceeded, the API will reject further order creation requests
within the same minute and return an error response.
Refresh Token
When an access token expires, the client must generate a new token by calling the token endpoint with grant_type=refresh_token, passing the refresh_token, client_id, and client_secret in the body. The request must also include appropriate headers (Content-Type). The API will return a new valid access token, which should replace the old one for subsequent requests.
URL:
{base_url}/oauth/token
